# Rick and Morty Explorer

A full-stack web application for exploring characters, episodes from the Rick and Morty universe.

## Screenshot

<img width="1475" height="860" alt="rickandmorty_screen" src="https://github.com/user-attachments/assets/e1a6c579-74cd-44e1-8e1c-fd5f041d8d45" />

## Tech Stack
- **Backend:** Laravel, PHP, REST API
- **Frontend:** React
- **Data Source:** Rick and Morty API

## Features
- Browse characters, episodes
- Explore detailed information
- Search and filter data
